# InfluxDB capture tests

From the repository root, run the connector's tests with Docker Compose and
`flowctl` available:

```sh
uv run --package source-influxdb pytest source-influxdb
```

The snapshot tests start and seed the local InfluxDB 2.7 fixture once per pytest
session and remove it and its data afterward, including when a test fails.
Each session uses a separate Compose project and a Docker-assigned host port,
with a temporary copy of `test.flow.yaml` pointing to that port. The fixture uses
organization `estuary`, bucket `sensors`, and the test-only API token `made-up-token`.
The snapshot tests run `flowctl raw spec` and `flowctl raw discover`; the other
tests exercise capture and checkpoint recovery with mocked HTTP and TLS with
temporary certificates generated by `openssl`.

To preview the fixture's points, start and seed it manually on the default port
8087 used by `test.flow.yaml`:

```sh
docker compose -f source-influxdb/docker-compose.yaml up --detach --wait
source-influxdb/tests/fixtures/seed.sh
uv run --package source-influxdb flowctl raw preview-next \
  --source source-influxdb/test.flow.yaml --sessions 1 --delay 10s
```

Remove the fixture and its data after previewing:

```sh
docker compose -f source-influxdb/docker-compose.yaml down --volumes
```
